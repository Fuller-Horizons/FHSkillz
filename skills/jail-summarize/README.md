# jail-summarize

Decision-forcing executive communication: lead with the answer, translate
technical findings into business consequences (revenue, liability,
resilience, competitive position, cost, control, timing), and end on the
decision the brief exists to force — no FYI briefs. Seven-part structure,
facts vs analysis labeled, depth calibrated to the audience (board / exec /
line manager).

Renamed from `jail-exec-brief` at plugin 0.24.0 — the broader name reflects
that it summarizes any complex material into a decision-ready brief, not
only formal "exec briefs." Same discipline, version lineage in git.

Boundaries: not raw research packets (jail-research), not full decision
analysis (jail-decide — this skill presents it), not plain meeting/thread
recaps (jail-cpr's debrief or direct summarization).
