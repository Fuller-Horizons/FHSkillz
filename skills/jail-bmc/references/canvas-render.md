# Visual canvas rendering (layout only)

Use when an artifact, HTML, Docs, or Design tool is available. If none is,
use the fixed table from SKILL.md step 3. The content is identical; only
the layout changes.

## Grid layout (standard BMC, one page, landscape)

Five columns, with the bottom row split in two:

| Column 1 | Column 2 | Column 3 | Column 4 | Column 5 |
| :-- | :-- | :-- | :-- | :-- |
| Key partnerships (tall) | Key activities (top half) | Value propositions (tall) | Customer relationships (top half) | Customer segments (tall) |
| | Key resources (bottom half) | | Channels (bottom half) | |

Bottom row, two wide boxes: **Cost structure** on the left half, **Revenue
streams** on the right half.

## Each element in a block

- One short line of text (statement only).
- A badge: **V** (VALIDATED) or **H** (HYPOTHESIS). Never rely on color
  alone; the letter always shows.
- A small confidence tag (H / M / L) and the evidence ref number, for
  example `[3]`. An H element shows a dash instead of a ref.

## Page rules

- White page, black text, one neutral accent for V badges and a second
  neutral style (outline only) for H badges.
- Title line: venture name, stage, decision served, date.
- Under the grid, a strip with the top 3 to 5 risky assumptions, numbered
  in test order.
- A footer line: the label mapping (V = Fact-backed, H = Assumption) and
  the sources list.
- If the page is too crowded, keep the top 2 elements per block on the
  grid and put the full table on page 2.
- The JAIL-HANDOFF is never part of the rendered page.
